\# SalaryHub



SalaryHub is a web-based employee salary management application for organizations with employees across multiple countries.



\## Technology Stack



\- Java

\- Spring Boot

\- Angular

\- PostgreSQL

\- Spring Security and JWT



\## Main Features



\- Employee management

\- Salary management and revision history

\- Search, filtering, and pagination

\- Salary analytics

\- HR Manager authentication

\- Automated testing



\## Project Structure



\- `backend/` — Java and Spring Boot application

\- `frontend/` — Angular application

\- `docs/` — Requirements and technical documentation



\## Project Status



Requirements defined. Implementation in progress.
