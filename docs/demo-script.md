\# SalaryHub – Application Demo Script



\*\*Application:\*\* SalaryHub – Employee Salary Management System



\*\*Frontend:\*\* https://salaryhub-hr-management.vercel.app



\*\*Backend Health:\*\* https://salaryhub-backend.onrender.com/api/health



\*\*Suggested duration:\*\* 3–5 minutes



\## 1. Introduction



"Hello, this is SalaryHub, an employee salary management application designed to manage employee information and salary records across multiple countries.



The application is built using Angular, Java 21, Spring Boot, Spring Security, JWT authentication, and PostgreSQL."



\## 2. Login and Authentication



\- Open the deployed application.

\- Show the login page.

\- Log in using the HR Manager account.



"SalaryHub provides secure login for HR Managers. After successful authentication, the backend generates a JWT access token. The frontend uses this token when calling protected APIs."



Do not display or mention the actual password or JWT token.



\## 3. Dashboard



\- Show the dashboard.

\- Explain the employee and salary statistics.

\- Show the country and department breakdowns.



"The dashboard provides an overview of employees and salary information. Salary analytics are grouped by currency so that different currencies are not incorrectly added together."



\## 4. Employee Management



\- Open the Employees page.

\- Show the employee list.

\- Demonstrate search and filtering.

\- Open an employee's details.

\- If time permits, demonstrate adding or editing an employee.



"The employee module supports employee information management, searching, filtering, and pagination."



\## 5. Salary Management



\- Open an employee's salary details.

\- Show the salary history.

\- Demonstrate adding a salary revision with an effective date, if appropriate.



"SalaryHub maintains salary revision history instead of simply overwriting the previous salary. Each salary record has an effective date and currency. This also supports future-dated salary revisions."



\## 6. Global Salary Records



\- Open the Salary Records page.

\- Demonstrate searching and filtering by country, department, and currency.

\- Show pagination.



"This page provides a consolidated view of salary records across employees and supports filtering and pagination."



\## 7. Logout



\- Log out of the application.

\- Show that the user returns to the login page.



"Protected application features require authentication. The user can securely log out when finished."



\## 8. Closing



"SalaryHub demonstrates employee management, salary revision history, authentication and authorization, analytics, and database integration.
